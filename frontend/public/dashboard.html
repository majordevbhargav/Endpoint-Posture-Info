How remediation works
Applications are discovered from the posture checks already run against each endpoint. Move an application to Business Relevant or Business Irrelevant, then select the applications you want removed. Uninstall Selected removes them remotely, over PowerShell Remoting, from every endpoint that currently reports the application installed. Protected applications, such as security agents, OS components, and drivers, cannot be uninstalled from this console.
